# 新大地生产排程约束及指标

## 数据和计划时点

- 订单需求表取客户简称、产品编码、订单型号、订单数量、接单日期、发货日期及客户优先级。库存和安全库存按产品编码连接。日期序列依工作簿所用纪元解释，发货日无具体时刻时使用当日 23:59。有效时区为北京时间。
- 接单时点晚于排产或重排时点的订单不纳入当次目标或库存分配。库存为静态快照，随计划保留已分配库存。物料延期事件给受影响编码的待加工任务设置可用时间；这是对可加工时点的输入，齐套率待企业补数。
- 先按客户优先级、接单日期、发货日期和稳定订单编号分配现有库存。正净需求减去订单待生产量形成补库需求，补库低优先级，执行件数向上取整。未取整净需求守恒单独核对。仅对有订单编码生成补库。
- 缺库存和安全库存临时按 0 并列异常。多型号产线缺大换型时长时暂用 2 小时并提示待确认。无适配线的需求列入未排；公开文档不记录企业实际产线、型号与需求统计。

## 硬约束和重排

- 型号族用于线体适配及换型，订单原始型号另保留。相同产品编码连续加工无换型。同族不同编码用该线小换型。异族用该线大换型。初始线体型号未知，第一单无换型。换型和加工占用同一条线。
- 工时为件数除以小时产能后向上取整到分钟。单任务在一个可用区间内加工，换型和加工采用连续区间。生产周期保留为描述数据。可在可选工作表「产线日历」填线号、可用开始和结束，每行一个区间。未提供日历时按连续可用。
- 量纲守恒要求每个任务的安排件数与未排件数等于生产任务件数。订单交期是优化目标。规则与候选计划均由独立校验器检查。
- 重排默认冻结未来 8 小时内开始换型的任务。保留已完成记录及仍可执行的在制任务。与故障或物料释放冲突的冻结任务及受其前序影响的同线安排可以重新安排。当停机截断正在加工的批次，使用人工输入的实际完工量保留历史段，余量重新排程。回放中，截止事件时点前已计划完成的任务视为已执行。最小扰动候选优先保留可继续执行的原线体与开工时间，再把新增和冲突余量插入空档。

## 优化指标

- 准交率是按期完工订单数除以全部纳入订单数。未排完的订单计入分母。仅靠库存满足的订单以库存快照时点和接单时点的较晚者作为预计可交付时刻。
- 加权延期为有预计完工的订单的延期小时乘以权重后求和。客户优先级 1、2、3 的权重依次为 3、2、1。未排订单数、未排订单件数和未完成补库件数单列。
- 产线负载是规划窗口内换型及生产占用时间除以可用分钟数。负载 CV 为标准差除以均值。换型指标按实际占用小时合计。总工期从本次方案的原始计划起点到最后一个完工时点。
- 局部搜索先尽量降低未排订单的优先级权重和件数，再降低补库缺口。随后以可复现的加权分数比较准交与延期、换型、负载 CV 和总工期。这四项在交付优先方案的权重为 0.70、0.10、0.10、0.10，在换型优先方案为 0.30、0.50、0.10、0.10，在负载均衡方案为 0.35、0.10、0.45、0.10，在客户优先方案为 0.60、0.15、0.15、0.10，在综合均衡方案为 0.45、0.25、0.20、0.10。延期按订单数及规划期归一化，换型和总工期按规划期归一化。重排额外计入任务移动比例与开工时间偏移。
- 对照是确定性优先级规则基准。人工计划、设备日历和物料数据应由企业提供，取得后用同一窗口复跑并报告历史比较。
