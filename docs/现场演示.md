# 新大地生产自动排程现场演示

公开版使用合成演示工作簿，不使用企业原始订单或生产统计。

~~~powershell
.\.venv\Scripts\python.exe scripts/create_demo_workbook.py
.\.venv\Scripts\python.exe -m aps.product serve --demo --source .var/demo.xlsx
~~~

| 时长 | 操作 | 现场核对 |
|---|---|---|
| 约 1 分钟 | 导入合成工作簿，展开异常，下载需求对账。 | 对照生成器中的虚构订单、库存和产线，检查库存覆盖、补库和无适配线提示。 |
| 约 2 分钟 | 生成方案，比较交付优先和换型优先，筛选一条演示产线。 | 准交率、换型时间和未排数量与方案联动。 |
| 约 2 分钟 | 选择草案，打开作业并调整时间或产线，锁定任务。 | 约束校验通过后生成新版本，原版本仍可查看。 |
| 约 2 分钟 | 提交审批，切换主管后批准、发布，再由车间签收。 | 核对角色、版本和操作记录。 |
| 约 2 分钟 | 登记实际开工、结束与完成量，按报工重排。 | 已完成产量保留为历史，剩余量进入新草案。 |
| 约 1 分钟 | 导出当前方案。 | 工作簿中的计划、交付、换型和异常与界面一致。 |

紧急插单可使用 DEMO-6201 编码与 6201-2RS 型号，输入自行设定的合成数量。交期须晚于重排时点。故障截断在制作业时，需填写停机前实际完成件数。设备日历、物料齐套及人工排产对照在企业试点阶段另行确认。
